# ADR-016：虚拟遥控器（App 栏）

- 状态：已采纳（P0 手持壳 + 键盘联动 + 本机外设绑定）
- 日期：2026-08-20
- 模板：**6（Velxio 宿主）** + **1（采集→管道→展示）**；应用清单仍为 ADR-014 的 4-lite
- 落点：`velxio/AppS/web/VirtualRemote*`；综合窗口中栏经 `@center` 套壳
- 不选：新仓独立遥控 App；替换 UART 控制面；Vue

## 决策

1. 综合窗口「应用」栏升级为 **虚拟遥控器**：外形模仿手持主机（屏 + 十字键 + A/B + 顶栏三键），不是新产品。
2. **屏** = 现有 `VapHost`（对话气泡 / 视觉预览），UART0 仍是 MCU 唯一控制面。
3. **按键联动键盘**：方向键滚动字幕；`Z`/`Enter` = A 发送；`X`/空格 = B 按住说话。点击遥控按键同时把 `button-press` 打到画布上已绑定同一主键的 pushbutton。
4. **外设绑定本机**：顶栏蓝/白/红键分别绑定摄像头、麦克风、喇叭（`getUserMedia` + TTS 开关）。视觉示例默认开摄像头；对话示例默认开麦和喇叭。

## 后果

- 电路视图的浮窗对话/视觉不变；仅 `viewMode = studio` 的中栏套遥控壳。
- 在输入框 / Monaco 打字时不抢键。
- Key 仍不进浏览器；TTS 受喇叭绑定开关约束。
